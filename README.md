# Oversized Tee Sizing Guide

A short, no-fuss guide for picking the right size when you buy an oversized t-shirt online.
Nothing to install. Just read it.

## 1. Measure a tee you already like
Lay it flat, measure straight across the chest, and write the number down.
Use that number instead of the letter on the tag.

## 2. Compare it to the size chart
If a brand lists the chest measurement for each size, match your number to it.
Unisex oversized tees often work this way. The Poisoned Store, for example, lists
unisex oversized fits in sizes S to XXXL (check the product page for the exact chart).

## 3. Decide how loose you want it
- Relaxed: pick the size that matches your number.
- Very baggy: go up one size, but only if the chart supports it.

## 4. Check the fabric
Heavier cotton hangs better on a loose cut. Combed cotton at 220-240 GSM
is on the heavier side. Look for the GSM on the product page.

## 5. Read the exchange policy
Sizes can still be off, so find the exchange rules before you order.
